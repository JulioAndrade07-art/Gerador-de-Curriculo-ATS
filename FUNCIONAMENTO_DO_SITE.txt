          GERADOR DE CURRÍCULO ATS - DOCUMENTAÇÃO DE FUNCIONAMENTO

1. VISÃO GERAL DO SISTEMA
--------------------------------------------------------------------------------
O Gerador de Currículo ATS é uma aplicação web voltada para a criação de 
currículos profissionais perfeitamente formatados para passar pelos sistemas de 
Rastreamento de Candidatos (ATS - Applicant Tracking Systems). O sistema permite 
que o usuário preencha seus dados, importe experiências diretamente do PDF da 
Carteira de Trabalho Digital (CTPS), meça o nível de otimização ATS em tempo real 
e exporte o documento final em PDF (com 100% de paridade entre Desktop e Celular) 
ou em formato editável Word (.docx).


2. ARQUITETURA E TECNOLOGIAS UTILIZADAS
--------------------------------------------------------------------------------
A aplicação é dividida em dois módulos principais:

A. FRONTEND (frontend-react)
   - Framework: React 19 + Vite + TypeScript
   - Estilização: Vanilla CSS customizado (`src/index.css`)
   - Gerenciamento de Estado: React Context API (`ResumeContext.tsx`) com 
     persistência automática no LocalStorage.
   - Drag and Drop: `@dnd-kit/core`, `@dnd-kit/sortable` para reordenação 
     manual de experiências e formações no desktop e touch no mobile.
   - Exportação:
     * PDF: `html2pdf.js` + `jsPDF` renderizando uma cópia off-screen com 
       largura fixa A4 (794px), injetando estilos rígidos inline.
     * DOCX: `html-to-docx` com fallback automático para formato Word nativo Blob.
   - Analytics: Utilitário leve e privacy-friendly (`analytics.ts`) sem uso de cookies.
   - SEO Técnico: `robots.txt`, `sitemap.xml`, Canonical Tags e Meta Tags Open Graph.

B. BACKEND (backend-node)
   - Runtime: Node.js com TypeScript e Express
   - Upload & Validação: Multer (limite de 5MB, aceite exclusivo de PDF).
   - Segurança: `express-rate-limit` (10 requisições por 15 minutos por IP).
   - Leitura de PDFs: `pdf-parse` (extração direta de texto de PDFs da CTPS) 
     e `tesseract.js` (fallback para OCR).


3. COMPONENTES E FUNCIONALIDADES DO FRONTEND
--------------------------------------------------------------------------------
- ResumeContext (`src/contexts/ResumeContext.tsx`):
  Guarda todos os dados do currículo e sincroniza instantaneamente com a 
  pré-visualização e com o LocalStorage.

- FormPanel (`src/components/FormPanel.tsx`):
  Formulário em sanfona (accordion) composto por:
  * Header com favicon, título e botão "Limpar Formulário" (com confirmação via 
    `ConfirmClearModal`).
  * ProgressBar: Barra de progresso dinâmica que calcula o percentual de preenchimento.
  * Seção Dados Pessoais: Nome, idade automática por data de nascimento, 
    máscara de telefone `(DDD) 00000-0000`, e seletores de Estado (UF) e Cidade 
    integrados à API do IBGE com cache em `sessionStorage` e debounce de 300ms.
  * PeriodPicker: Seletor intuitivo de Período (Mês e Ano) com opção "Presente".
  * ExperienceEditor / EducationEditor: Listas ordenáveis com alça de drag & drop (`⠿ Arrastar`).
  * Botões de Exportação (DOCX e PDF) integrados ao modal de apoio social (`FeedbackSupportModal`).
  * Rodapé com transparência de privacidade sobre uso de estatísticas anônimas.

- PreviewPanel (`src/components/PreviewPanel.tsx`):
  Renderiza o currículo em uma folha A4 virtual em tempo real, contendo no topo o 
  `AtsBadge` (insígnia de pontuação ATS colorida: Vermelho, Amarelo ou Verde).

- AtsPanel & AtsBadge (`src/components/AtsPanel.tsx`, `src/components/AtsBadge.tsx`):
  Calcula pontuação ATS de 0 a 100%, analisa palavras-chave da vaga e sugere melhorias.

- CtpsImporter (`src/components/CtpsImporter.tsx`):
  Componente para upload do PDF da Carteira de Trabalho Digital e importação direta.


4. ESTRUTURA DE SEO TÉCNICO E INDEXAÇÃO
--------------------------------------------------------------------------------
- `public/robots.txt`:
  Define permissão total para crawlers (`User-agent: *`, `Allow: /`) e aponta o 
  caminho oficial do `sitemap.xml`.

- `public/sitemap.xml`:
  Lista a URL canônica `https://gerador-de-curriculo-ats-ten.vercel.app/` com 
  frequência semanal. Novas páginas (blog, sobre) devem ser incluídas neste arquivo.

- `index.html`:
  Configurado com `<meta name="description">` (até 160 caracteres), `<meta name="robots" content="index, follow">`, 
  `<link rel="canonical">`, Open Graph (Facebook/WhatsApp) e Twitter Cards.


5. GUIA PARA EXPANSÃO FUTURA (PÁGINAS ESTÁTICAS E BLOG)
--------------------------------------------------------------------------------
Ao adicionar páginas de conteúdo estático ou postagens de blog:
1. Rotas amigáveis: Utilizar caminhos limpos como `/como-funciona` ou `/blog/nome-do-artigo`.
2. Metadados por página: Garantir que cada rota possua `<title>` e `<meta description>` únicos (usando `react-helmet-async` ou similar).
3. Atualização do Sitemap: Adicionar cada nova rota ao `public/sitemap.xml`.
4. Pré-renderização (SSG): Como o projeto é uma SPA client-side em React, para garantir 100% de indexabilidade dos artigos do blog pelo Google, considerar ferramentas de SSG como `vite-react-ssg`, `astro` ou pré-renderização estática das rotas públicas.


6. COMO EXECUTAR O PROJETO LOCALMENTE
--------------------------------------------------------------------------------
Passo 1: Rodar o Backend (Node.js)
  $ cd backend-node
  $ npm install
  $ npx ts-node src/server.ts

Passo 2: Rodar o Frontend (React + Vite)
  $ cd frontend-react
  $ npm install
  $ npm run dev
